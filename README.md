## 🏗️ Project Showcase

### 1. Car Insurance Quote Application (Featured Project)
A full-stack web application built to automate complex insurance premium calculations based on user risk profiles.

*   **Architecture & Pattern:** Built using the **ASP.NET MVC** (Model-View-Controller) design pattern to strictly separate business logic from the user interface.
*   **Data Layer:** Leveraged **Entity Framework (Code-First/Database-First)** to map C# models directly to a **SQL Server** instance, managing data migration and seeding seamlessly.
*   **Core Mechanics:** 
    *   **Dynamic Business Logic:** Implemented a calculation engine that processes user inputs (age, driving record, vehicle make/model) to dynamically compute quotes in real-time.
    *   **Data Integrity:** Utilized data annotations and model validation to ensure clean, secure inputs before processing or database entry.
    *   **Full CRUD Workflow:** Users can seamlessly create, read, update, and delete quote records via a secure dashboard.

### 2. OOP Fundamentals & System Design Labs
A collection of core C# console applications and class libraries designed to master advanced Object-Oriented concepts.

*   **Encapsulation & Security:** Built systems utilizing access modifiers and properties to protect internal object states.
*   **Polymorphism & Extensibility:** Developed modular components using method overriding, operator overloading, and **Interfaces** to ensure code can grow without breaking existing features.
*   **Reusability:** Created highly flexible, parameterized methods and abstract classes to minimize redundancy across applications.
